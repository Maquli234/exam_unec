# Exam App — бэкенд (этап 1)

## Запуск
    cd backend
    pip install -r requirements.txt
    export ADMIN_EMAIL=you@mail.com      # этот email при регистрации станет админом
    export JWT_SECRET=длинная-случайная-строка
    export GOOGLE_CLIENT_ID=...          # для входа через Google
    uvicorn app.main:app --reload        # документация API: http://127.0.0.1:8000/docs

## Открыть приложение
    http://127.0.0.1:8000  (фронтенд отдаётся самим сервером)

## Проверка
    python test_flow.py                  # прогоняет весь сценарий

## Что уже есть
- app/parser.py — разбор PDF/TXT (маркер «√/•» в тексте и векторные радиокнопки), текст дословно
- Аккаунты: email+пароль, Google, access (15 мин) + refresh (30 дней, ротация, отзыв)
- Админка (API): загрузка файла, предпросмотр, правка вопросов, список «на проверку»
- Экзамен: интервал номеров из файла, количество, вразброс, режим ответов immediate/end,
  таймер, сохранённые вопросы, итог с номерами ошибок
- Кеш банков: TTLCache (для продакшена заменить на Redis)

## Что осталось
- Фронтенд (React): экран экзамена, админ-панель, RU/AZ, светлая/тёмная тема
- Таймер: сервер отклоняет ответы после истечения; автозавершение делает клиент
- Redis, Alembic-миграции, лимиты запросов, HTTPS/CORS для продакшена
